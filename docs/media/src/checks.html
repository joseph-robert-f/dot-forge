What the checks establish

Geometry findings and printing decisions stay separate

A native solid can pass while its exported mesh fails. A mesh can pass while its physical use is unknown.

1

Native checks

Automated

Establishes

The model reopens. FreeCAD also checks the solid and a STEP round trip.

Does not establish

That the exported mesh is valid.

2

Independent STL checks

Automated, separate code

Establishes

Topology, dimensions, volume, intersections, single-solid profile. FreeCAD adds step and hole checks.

Does not establish

Strength, clearances, or print suitability.

3

Preview review

Person compares five views

Establishes

Whether the actual STL shows the requested features.

Does not establish

Dimensions, strength, or user approval. A render alone is not approval.

4

Printing and physical

Open. Never auto-passed

Still to do

Printer and material, wall thickness, clearances, orientation, supports, slicing.

And finally

User visual approval and a physical test.

Never counted as a pass

  • Failed
  • Skipped
  • Unavailable
  • Inconclusive
geometry_state and print_state are reported separately. A valid geometry result normally ends in needs_review.
