How it works

From request to verified evidence bundle

Your dot runs these public CLI commands on its Linux cloud computer. Every attempt gets a new output directory.

01

request.json

Pick a family. Supply width, depth, and height from 5 to 100 mm.

request.json
02

check-request

Checks the strict contract. No geometry yet.

check-request
03

run

Generate. Reopen the native model. Validate the exported STL. Render five views.

run --output …
04

inspect

Verifies integrity. Exit code 5 means manual or printing review is required.

inspect --run …
05

bundle

Packs the finalized evidence into a ZIP outside the run directory.

bundle --run …
06

verify-bundle

Run it on the copy you retrieve from the durable destination.

verify-bundle ….zip
Between steps 03 and 04, a person compares the front, side, back, top, and oblique renders with the request.
Still open after step 06: printer and material settings, slicing, orientation, supports, and a physical test.
